Découvre toutes les cases sans mine. Un chiffre indique combien de mines se cachent dans les 8 cases voisines.

- Ton premier choix est toujours sûr.
- **Clavier** : une fois dans le champ, les flèches déplacent la case active, `Entrée` ou `Espace` la révèle, `F` pose ou retire un drapeau.
- **Souris** : clic pour révéler, clic droit pour un drapeau.
- **Écran tactile** : active le bouton « Mode drapeau » pour poser des drapeaux au lieu de révéler.
- Un drapeau marque une case que tu penses minée. Les cases drapeautées ne sont pas révélées par erreur.
